# 🚀 Data Analytics & Power BI Hub

An interactive, beginner-friendly web dashboard built with **Streamlit**, **Pandas**, and **Plotly**. Upload any CSV or Excel file to instantly clean your data, explore interactive visuals, and export formatted datasets with auto-generated DAX formulas for Power BI Desktop.

---

## ✨ Features

- 📁 **File Upload Support**: Upload `.csv` or `.xlsx` files directly from your browser.
- 🧹 **One-Click Data Cleaning**: Automatically removes duplicate rows and fills missing values.
- 📊 **Simple Visualizations**: Generate customizable Bar Charts, Donut Charts, and Histograms in a dark-mode theme.
- 🟡 **Power BI Export**: Download cleaned datasets formatted for Power BI alongside auto-generated DAX measures.
- 🎨 **Modern Interface**: Custom gradient background with responsive metric summary cards.
